## 压力位与支撑位(`levels.mjs`)
只描述价位在哪、有多强,**不报触及概率**。
| 来源 | 价位 | 口径 |
|---|---|---|
| 期权 | 看涨 OI 墙(上方)、看跌 OI 墙(下方),强度 = 占该方向总 OI 的 %;ΔOI 对比上一快照 | 只算 `options_max_dte` 天内到期;优先用次日补读的收盘 OI(`oi_basis` 标明) |
| 期权 | gamma 翻转位【推算】 | 假设做市商与客户反向;按行权价累计净 gamma 的符号翻转处 |
| 价格 | 均线、N 日收盘高低、52 周高低 | 日线收盘价 |
| 卖方 | 目标价最低 / 四分位 / 中位 / 最高 | 逐家券商,不含 `Mean` 行 |
| 合成 | 共振区:相距 ≤ `zone_pct`% 且来自 ≥2 类来源 | 只保留距现价 `max_distance_pct`% 以内的价位 |

## 估值区间(`valuation.mjs`)
**问题**:一年后,按市场通常给这家公司的估值,合理价格在哪?
1. **一年后的前瞻 EPS**:在 [今天+1 年, 今天+2 年] 这 12 个月里,按财年结束月份对 FY1–FY4 一致预期加权(FY1 的结束月份取自 `estimates FY1.csv` 的财年标签);FY4 缺且要用时按 FY3/FY2 增速外推并标记。分三档:均值 − 1 个标准差 / 均值 / 均值 + 1 个标准差(`eps_band: sd`;2026-11-24 首跑发现最低/最高常被单个极端分析师拉偏,如 NVDA FY3 最低 11.02 而均值 21.75、σ 2.8;缺标准差时退回最低/最高)。
2. **退出市盈率**:自身过去 36 个月 NTM P/E 的 25 / 50 / 75 分位(对齐 Research OS「前瞻估值在自身 3 年区间的分位」);10 年分位作对照。
3. **主区间**:悲观 = 最低 EPS × 25 分位,中性 = 均值 × 中位,乐观 = 最高 × 75 分位;另给 3×3 全矩阵。
4. **第二个锚「估值不变」**:一年后 EPS × 今天的市盈率,只算盈利增长、不假设回归。现价市盈率在 3 年历史的极端(低于 `regime_pctile` 或高于 100−`regime_pctile`)时标 `regime_gap`:历史估值可能已不代表当前市场(治理、周期顶、利率环境变化),两个锚要一起看。
5. **交叉核对**(只并排,不进公式):卖方 12 个月目标价分布、1 年历史波动区间【推算】、现价市盈率的 3 年 / 10 年分位。
6. **不适用**:一年后 EPS 均值 ≤ 0(亏损)、有效 P/E 少于 `pe_min_months` 个月(上市不久)、FY1 财年标签缺失。

## 交接(`handoff.mjs`)
每只标的压成摘要(最近压力/支撑、共振区、估值区间与两个锚),和上一交易日比出变化;编号 = 内容哈希,内容不变编号不变。格式见 `schema/README.md § handoff`。
