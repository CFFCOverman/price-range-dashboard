# 每日合理估值与修订处理

合理价值使用股东现金流折现（FCFE），与历史倍数区间分开。模型先估价值，再以模型基准 NTM EPS 计算隐含合理 PE；不以现价倒推合理价值，不以分析师目标价倒推目标倍数。

`V = Σ FCFE_per_current_share(t) / (1 + Ke)^year_fraction(t) + terminal_FCFE_next / (Ke - g) / (1 + Ke)^year_fraction(last_date)`

- FCFE 需完成经营现金流、再投资和净债务融资桥接；折现率使用股权成本。不可把 FCFF 用股权成本折现，也不可再次扣净债务。现有多余现金如需加回，应单独建模其可分配现金流，并避免把已计入现金流的利息和现金重复计价。
- 预测期采用明确的支付日期，按实际天数 / 365.25 折现。首期只含估值日之后的现金流，不能把已实现财年部分再计入。日期过去后必须滚动模型。
- 每股单位统一为当前稀释后股数的权益份额，未来 SBC、融资及股本变化须处理。若以经济成本扣除 SBC，不可再对相同成本重复扣稀释。回购不能一面作为分配现金流，一面无成本缩小分母。
- 一般使用约五年明确预测，再将增长与再投资渐进收敛到稳定期。基础引擎允许至少两期，但缩短预测期必须有经济依据。终值要求 `0 <= g < Ke`。终值占比在页面公开，情景区间不是概率区间。
- 一致预期各指标可能不是同一分析师集合。CFO−Capex 不等于独立 FCF 共识时，必须核验口径或建立一致的自有现金流桥，不能静默混合。

## 输入与来源

私有输入放在 `Assets/fair-value/*Fair Value Inputs.json`。文件内容为 `{document_type:"fair-value-inputs-v1",models:[],observations:[],events:[]}`，可与 Assets 一起扫描或单独导入。其他 JSON 不自动读取；研究底稿不会自动变成生产估值。

模型使用 `schema:fcfe-v1`，字段见 `src/js/valuation/fair-value.js`。必填代码、币种、模型 ID、模型日、复核时间及截止日、来源、现金流口径、归一化说明、现金流时点说明、模型基准 NTM EPS、固定财年盈利基准及三种情景。`status:reviewed` 表示建模者已经核验输入，软件校验并不能替代研究核验。模型 ID 不可复用修改内容；同日多次修订按复核时间排序。

每个情景包括依据、股权成本、永续增长率、稳定期下一年 FCFE，以及日期/每股现金流/来源列表。模型没有默认填充的风险溢价、终值或稀释率。纯合成测试在 `tests/test-fair-value.mjs`，不得用于真实证券。

盈利观察使用固定财年 `YYYY-MM`、EPS、日期、观察时间、口径、币种和来源。网页访问时间不等于提供商更新时间；可明确保存未知更新时间为 null。年度模型 EPS 不自动伪装成 NTM。

事件包括唯一 ID、证券代码、标题、来源、观察时间及 `requires_review`。模型以 `reviewed_event_ids` 列出已处理的事件。当前没有自动新闻分类器或 FactSet 推送订阅；未导入的事件无法被软件发现。

## 更新与复核

同一财年的盈利发生变化（包括负数），或币种/口径改变，模型转为待复核；不将 EPS 下调机械等比例施加到所有远期现金流。复核后新版本计算新价值。任何修订均触发复核，未用任意百分比阈值掩盖小修订。

超过模型复核日、数据超过模型指定的 0–7 个日历日有效期、缺少同财年核验或存在未处理事件，也会失效。日期统一按纽约解释。NTM 随时间滚动，与固定财年分析师修订分开。

页面打开且文件夹已连接时，每 60 秒检查本地文件变化；有新数据后重新计算并记录。未变更文件不会重复解析；跨日也记录一次。手动价格/EPS输入仍为情景工具，不修改模型假设。切换浏览器/清除本地存储会影响浏览器记录，使用导出按钮备份。它不代表 FactSet 每60秒更新，也不代表关闭页面后仍监控。

`npm run fair-value:record` 仅读本地清单、公司和预测文件及私有输入，保存 `Assets/fair-value/ledger.json`、`latest-review.json`。不联网、不运行抓取器或交易信号。日内新观察保留独立记录，同一观察重复运行去重。未建模/待复核记录的当前合理价为空，旧模型及来源仍保留审计。命令尚未安排定时运行。

“第一时间”须分别验证提供商更新时间、获取时间和本地导入时间。现在仅实现最后两步的记录和导入后响应；浏览器能看预测不等于拥有实时数据 API 权限。

## 当前实数覆盖

2026-10-01 已直接核验 NVDA 当前盈利和现金流表，并私下保存来源。尚未完成稀释、现金流桥、剩余财年及折现率的模型核验，生产模型列表为空。其他清单证券也未完成 FCFE 建模。页面应显示“待建模”，不可宣称已交付全清单每日合理价格。
