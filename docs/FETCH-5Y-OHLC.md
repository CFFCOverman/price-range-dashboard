>

> 它们找的菜单名、按钮文字、点击顺序,全是照着当年"自动加成交量"那条走通过的路**推测**出来的。

## 1. 这件事为什么值得折腾

现在每只票的 Charting 导出**正好 252 行 = 一年日线**,而且**只有收盘价**,没有 Open / High / Low。

- **只有一年**:回测里 h=63(三个月持有期)的样本,去掉重叠之后只剩大约 10 个独立聚类。
  10 个样本什么都验不出来 —— 项目里现在所有"未通过验收"的指标,有相当一部分卡的不是策略,是样本量。
  拉到 5 年 ≈ 1260 行,独立样本变成 50 个左右,这才是唯一能真正改变验收结论的动作。
- **没有 OHLC**:整整六类技术指标根本无从算起(K 线实体/影线、ATR 通道、KD/威廉指标、
  枢轴点、一目均衡表、跳空缺口)。它们现在在验收表里只能标 `pending_no_ohlc` —— 不是"没通过",是"压根没测"。

**关键事实(从代码读出来的,可靠):导出的时间跨度和列,不是下载按钮的选项,而是你 FactSet 账号里
那张"保存好的图表布局"的属性。** 当年的成交量列就是这么解决的 —— 手动在图上加了 Volume 序列并保存布局,
之后每一轮导出都自带成交量。5Y 和 K 线是**完全同一类**东西。

## 4. 两个开关:`FS_NO_5Y` 和 `FS_NO_OHLC`

**从代码读出来的(可靠):**

| 环境变量 | 设成 `1` 的效果 | 不设时的默认 |
| --- | --- | --- |
| `FS_NO_5Y=1` | **不再**尝试自动切 5 年跨度 | 会尝试 |
| `FS_NO_OHLC=1` | **不再**尝试自动切 K 线 / OHLC | 会尝试 |
| `FS_NO_VOLUME=1` | **不再**尝试自动加成交量序列 | 会尝试 |

判定逻辑严格是"等于字符串 `1` 才关闭"。写 `true`、`yes`、`0` 都等于**没关**。

**什么时候该关掉?** 做完第 6 节的手动设置之后。布局已经手动摆好并保存了,
再让脚本去点它,反而可能把你摆好的图点乱。那时候三个都关掉最省心。

### PowerShell 写法

PowerShell **不认** `set XXX=1`。它的写法是 `$env:`:

```powershell
# 只对当前这个 PowerShell 窗口有效
$env:FS_NO_5Y = "1"
$env:FS_NO_OHLC = "1"
.\run-factset.bat
```

一行搞定(用 `;` 隔开):

```powershell
$env:FS_NO_5Y="1"; $env:FS_NO_OHLC="1"; .\run-factset.bat
```

**用完取消**(否则这个窗口后面每次跑都是关着的):

```powershell
Remove-Item Env:\FS_NO_5Y -ErrorAction SilentlyContinue
Remove-Item Env:\FS_NO_OHLC -ErrorAction SilentlyContinue
```

检查现在是开是关:

```powershell
$env:FS_NO_5Y     # 打出 1 = 已关闭尝试;什么都不打 = 会尝试
```

### cmd(命令提示符)写法

cmd 用 `set`,**等号两边不要加空格**:

```bat
set FS_NO_5Y=1
set FS_NO_OHLC=1
run-factset.bat
```

一行搞定 —— 注意 `1` 和 `&&` **中间不能有空格**,否则变量值会变成 `"1 "`(带一个尾随空格),
那就不等于 `1` 了,开关等于没生效:

```bat
set FS_NO_5Y=1&& set FS_NO_OHLC=1&& run-factset.bat
```

**用完取消**(等号后面留空):

```bat
set FS_NO_5Y=
set FS_NO_OHLC=
```

检查现在是开是关:

```bat
echo %FS_NO_5Y%
```
打出 `1` = 已关闭尝试;打出 `%FS_NO_5Y%` 这个原样字符串 = 没设,会尝试。

> 顺带一句:`run-factset.bat` 里有 `setlocal`,但那只影响**它自己内部**设的变量。
> 你在外面设好的环境变量照样会被子进程继承,上面两种写法都有效。


三个格子分别读:

| 位置 | 可能的值 | 含义 |
| --- | --- | --- |
| 跨度 | `跨度 5.0 年` | ✅ **成了!** 5Y 拿到了 |
| | `跨度仍是 1 年` | ❌ 还是一年,没切成 |
| | `跨度只有 0.2 年` | 多半是新上市股,历史本来就短,不是布局问题 |

| K 线 | `含 OHLC` / `仅收盘价` | Open/High/Low **三列齐全**才算 `含 OHLC`,缺一列都算没有 |

判定门槛(从代码读出来的):跨度 ≥ **4.5 年**才算 5Y 达标(留了半年余量)。

   所以导出永远只有 Close,这不是导出少给了,是图里就没有)
3. 图上有一条 **Volume** 序列(如果你之前已经加过,就别动它)

**推测的操作路径:**

1. 用浏览器打开 `https://my.apps.factset.com/workstation/charting/`(用你自己的账号,正常登录)。
2. 输入一个代码把图画出来,比如 `NVDA-US`。
3. **改跨度**:*推测* —— 点工具栏上的 `5Y`;如果没有这一排,找 `Date Range` / `Period` / `Zoom`
   下拉,选 `5 Years`;如果只有起止日期框,把起始日改成五年前的今天。
4. **改图表类型**:*推测* —— 找 `Chart Type` / `Style` / 折线图小图标,改成 `Candlestick`(或 `OHLC`)。
5. **确认成交量还在**:图下方应该有一条柱状的成交量副图。没有就加回来
   (*推测*:`Studies` / `Indicators` → `Volume`)。
6. **保存布局** —— **这一步最关键,漏了前面全白做**:
   *推测* —— `Layout` → `Save`;也可能叫 `Save Layout` / `Save as Default` /
   `Set as Default Chart`,或者在齿轮图标里。
   **必须存成"以后打开 Charting 默认就是这样"**,而不是"另存为一个叫某某名字的布局"。
   如果只有"另存为具名布局"这一种选项,那就再找找有没有"设为默认"的地方,
   并且**把这一步的截图发给我** —— 那意味着脚本可能还需要额外一步去加载那个具名布局。

### 7.2 验证有没有成功

### 7.3 注意:脚本可能会把你摆好的布局点乱

这是真实风险,不是吓唬人。三个 `try*` 函数里的选择器是猜的,猜错了就会在页面上**乱点**,

所以第 7.1 做完之后,**请务必按 7.2 那样把 `FS_NO_5Y` / `FS_NO_OHLC` / `FS_NO_VOLUME` 全设成 1**。

万一真被点乱了:回 FactSet 里重新摆一遍存一遍就行,数据本身不会有任何损坏
(脚本只读不写你的 FactSet 账号数据,它做的最坏的事就是把图点成一个奇怪的样子)。
